# ProductCards for 1C 7.7

Генератор JPG-карточек товаров для отправки в группу с клиентами.

## Как получить Windows-программу

1. Создайте новый репозиторий на GitHub, например `product-cards-1c`.
2. Загрузите в него файлы проекта.
3. Откройте вкладку **Actions**.
4. Выберите workflow **Build Windows EXE**.
5. Нажмите **Run workflow**.
6. После завершения откройте выполненный запуск и скачайте artifact `ProductCards-Windows`.
7. Внутри архива будет `ProductCards.exe`.

Также сборка запускается автоматически после отправки тега вида `v1.0.0`.

## Запуск программы

1. Запустите `ProductCards.exe`.
2. Выберите папку базы 1С, где находятся `SC354.DBF`, `SC377.DBF`, `SC203.DBF`.
3. Выберите папку `Photo`.
4. Нажмите **Обновить каталог**.
5. Отметьте нужные группы: например, «Вафли» или «Печенье».
6. При необходимости включите фильтр по производителю.
7. Выберите товары и нажмите создание карточек.
8. Укажите папку для сохранения JPG.

## Что используется

- `SC354.DBF` — коды, названия и группы товаров.
- `SC377.DBF` — цены.
- `SC203.DBF` — типы цен; используется тип `N`, то есть VIP-цена.
- Фото ищутся по точному имени кода: `00-11117808.jpg` или `ЦБ-00001592.jpg`.

На карточке выводится только `Цена: ... ₽/кг`, без слова «VIP». Наименование сохраняется как в 1С. Подпись располагается в нижней белой области и не закрывает фотографию.

Программа работает только на чтение и не меняет файлы 1С. Отправка в мессенджер выполняется вручную.
